# Neon Confluence · 霓虹汇流

A real-time, explorable cyberpunk river city that runs in the browser.

**Play:** http://aidanduncan.me/cyberpunk_world/Opus55/

You can also download `index.html` and open it directly; it works offline.

## What it is
- **Single file:** everything is one self-contained `index.html`, drawn with WebGPU. No game engine or 3D library is used.
- **Everything generated by code:** there are no image, model, font or sound files. Neon sign lettering is rendered at load time from the system fonts.
- **Setting:** a night city in light rain, set among mountains and built around the meeting point of two rivers. It is inspired by Chongqing and Shanghai, with skyline ideas from Hong Kong and Kuala Lumpur.
- **Districts:**
  - a dense hillside peninsula with stilted riverside buildings and a monorail that runs through a tower
  - a historic Bund-style waterfront facing a supertall business district across the river
  - a Central Asian / Mongolian quarter with a giant yurt-inspired dome and a night market
  - a West Lake / Suzhou garden district with causeways, a hilltop pagoda and walled gardens
- **Landmarks:** original towers inspired by (not copied from) the Shanghai Tower, Oriental Pearl Tower, Petronas Towers, Merdeka 118, Raffles City Chongqing and KL Tower.
- **What moves:**
  - neon signs, LED building facades and the river light show (searchlights, lasers and a drone show)
  - boats and flowing river water
  - monorail and metro trains, cable cars and road traffic
  - air taxis, drones and pedestrians
  - rain and drifting fog
- **Sound:** all synthesized live with the Web Audio API. There is a city hum and traffic, rain, the river, passing trains, light-show music near the waterfront, wind chimes and plucked strings in the gardens, and a horse-head-fiddle drone in the steppe quarter.

## Controls
| Input | Action |
|---|---|
| Mouse | Look (click to capture the mouse) |
| W A S D | Move |
| Space twice | Switch between walking and flying (like Minecraft creative mode) |
| Space / Shift | Fly up / down. Space jumps when walking |
| Hold R (or double-tap W) | Sprint while moving |
| Mouse wheel | Flying speed |
| 1 – 0 | Viewpoints |
| T | Rain on/off |
| M | Sound on/off |
| H | Stats (frame time, GPU time per pass) |
| Esc | Menu |

## Requirements
- A desktop browser with WebGPU: a recent Chrome or Edge.
- **Laptops with two GPUs:** Chrome on Windows ignores a page's request for the faster GPU. Open Windows Settings > System > Display > Graphics, add your browser and choose **High performance**. The start screen shows which GPU is in use.
- Quality adapts automatically. If frames get slow, the render resolution drops in small steps; it rises again when there is headroom.

## Performance
Target machine: RTX 4050 Laptop GPU, 2560x1440, Chrome. Measured during a scripted 60-second fly-through with GPU timestamp queries. See [verification/perf-report.md](verification/perf-report.md).

| | Average | 99th percentile | Worst frame |
|---|---|---|---|
| GPU time per frame | 9.5 ms | 11.5 ms | 12.9 ms |
| Target | 11 ms | 16.7 ms | 25 ms |

## How it was built
- **Team of agents:** five Claude agents worked in parallel on separate modules: terrain and gardens; buildings; water, bridges and light show; traffic, people and signs; atmosphere, post-processing and sound. They worked on top of a shared engine (deferred renderer, tiled lighting, froxel fog, temporal anti-aliasing, bloom).
- **Visual critic:** a separate critic agent that sees only screenshots reviewed ten fixed viewpoints and motion frames in each round. Its findings drove the fixes for the next round. Score progression and open items: [verification/critic-progress.md](verification/critic-progress.md).
- **Original request:** in [prompt.txt](prompt.txt).

## Building from source
```
cd source
npm install
node build.mjs          # writes ../index.html (minified)
node build.mjs --dev    # writes out/dev.html with capture and benchmark tools
node tools/capture.mjs --jpg --stats   # screenshots of the 10 viewpoints at 2560x1440
node tools/bench.mjs                   # 60-second GPU benchmark
node tools/functional.mjs              # controls and stability checks
```
The source code is in `source/src/`; `source/BRIEF.md` describes the engine contract each module follows.
